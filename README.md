# Nova Travel – Template Web Multi-pages

Nova Travel est un template web multi-pages moderne et responsive conçu pour des besoins d'agence de voyage. Le projet s'appuie sur une structure HTML5 sémantique et un design système cohérent via Tailwind CSS.

## Technologies utilisées

* HTML5 (Balisage sémantique et accessibilité)
* Tailwind CSS (Framework CSS utilitaire)
* Git & GitHub (Gestion de version)

## Architecture du projet

Le projet utilise une structure de composants UI standardisés et réutilisables (Header fixe, Footer, Cartes de destinations, Formulaires) déclinés sur plusieurs pages :

* index.html : Landing page avec section Hero et sélection des meilleures offres.
* html/voyages.html : Catalogue complet des séjours structuré en grille responsive.
* html/voyage-*.html : Pages de détail d'offre (Paris, Tokyo, Bali, Londres) basées sur un layout réutilisable.
* html/apropos.html : Présentation de l'entreprise et valeurs.
* html/contact.html : Formulaire de demande de devis et zone d'informations.
* assets/ : Ressources graphiques et visuels du projet.

## Caractéristiques techniques

* Layout 100% responsive (Breakpoints mobile, tablette et desktop).
* Design dark mode fondé sur la palette Slate.
* Séparation stricte de la structure HTML et des données de présentation.
* Composants d'interface homogènes d'une page à l'autre.
